## Known limitations

- Cryptography runs in pure Dart and has not been reviewed by outsiders.
- iOS and macOS: biometrics is still only an app-level lock (the password is stored in the Keychain); it is not bound to a key.
- Folder sync only works on desktop (Android cannot read SAF folders by path).
- Slowdown after wrong attempts only lives in memory (restarting the app clears it); the real protection is Argon2id.
- The standard Argon2id setting (3 passes, 64 MiB) takes about 1.3 seconds on a Note10+; weaker machines may take 3 to 4 seconds.
- Sync through Cloudflare is limited to about 1.5 MB (D1 row limit); beyond that, R2 is needed.
- A bug found by end-to-end testing: `Isolate.run` placed inside a method of VaultController captured `this` (which holds a Timer), making it "unsendable". All Argon2id operations now go through `lib/app/isolate_ops.dart`.
